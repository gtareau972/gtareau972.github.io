# Ressources officielles

Les liens que j'utilise au quotidien, vérifiés le **22 octobre 2026**. Chaque page de bonnes pratiques indique aussi ses propres sources en bas de page.

!!! info "Versions"
    La documentation Centreon affiche par défaut la dernière version (**26.10**, sortie le 16 octobre 2026). Pour une plateforme en 25.10, utiliser les liens contenant `/docs/25.10/`.

## Télécharger

[download.centreon.com](https://download.centreon.com/fr/) regroupe, pour l'*Infrastructure Monitoring* :

| Onglet | Contenu |
|---|---|
| Paquets | Installation d'un central en une commande (script *unattended*), installation manuelle |
| Connecteurs | 747 Monitoring Connectors, filtrables par catégorie, avec lien vers chaque procédure |
| Intégrations | Open Tickets (ITSM), Stream Connectors, plugins de notification |
| Agent | Centreon Monitoring Agent : installeurs Windows et commandes Linux |
| MCP | Serveur MCP pour assistants IA (bêta) |
| Sources | Modules et widgets open source, toutes versions, avec notes de version et sommes MD5 |
