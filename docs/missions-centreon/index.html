    Méthode de notation

    Score sur 100 rapporté aux critères disponibles : adéquation technique avec le CV (40), TJM (20 si le maximum publié atteint 500 €/j, 10 sinon), localisation (15 : toutes zones acceptées), fraîcheur calculée au jour de consultation (10 pour 0–2 jours, 7 pour 3–7, 3 pour 8–14, 0 au-delà), durée (10 : toute durée acceptée), intermédiaire identifié (2,5 sur 5). Sans TJM publié, la couverture tombe à 80 %. Une mission avec une exigence impérative non couverte n'est jamais classée prioritaire.
